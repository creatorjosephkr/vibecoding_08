# 저장소 활용 목적
본 저장소는 서울디지털대학교의 '바이브 코딩' 과정에서 진행하는 프로젝트 소스 코드를 올리고 관리하기 위한 곳입니다. 

# 프로젝트 소개
* 강의주차: 7주차 2교시 MINST 만들기
* 기능
  - 손글씨 인식 (숫자, 영문자)
  - 개별/단어/문장 인식 기능
  - 화면에 직접 글 쓰는 기능(스케치북)
  - 손글씨 업로드 기능
  - 카메라 사진 촬영 및 인식영역 설정 기능
  - **Google Handwriting Stroke API** 적용하여 인식률 획기적으로 개선
